# Capability probe

Small task. It exists to verify this agent can do real multi-turn work in this repo: read a
file, understand what is there, modify it, run the tests, and fix what breaks.

## What to do

1. Read `crates/farmerbob-core/src/ids.rs`. The id types are generated by a `define_id!`
   macro — note how that works before editing.
2. Give every id type a method `pub fn short(&self) -> String`, returning the first 8
   characters of the id's hyphenated UUID string. It must never panic, including if the
   string is somehow shorter than 8 characters.
3. Add unit tests in the same file covering: `short()` returns 8 characters for a fresh id,
   and two different ids produce different `short()` values.
4. Run `cargo test -p farmerbob-core` and make sure the whole crate still passes.

## Rules

- Touch no file other than `crates/farmerbob-core/src/ids.rs`.
- No `unwrap()`, `expect()` or `panic!` on any reachable path outside `#[cfg(test)]`.
- Do not add dependencies. Do not change any existing public signature.

When done, say in one line what you added.

## Handoff (required)

When you are done, write `.fb/handoff.md` in the repository root. Keep it under 300 words.

**Do not state anything the harness can check.** No test counts, no "all tests pass", no "this
handles empty input", no performance claims. Those are measured independently and a claim
about them adds nothing — the harness has already run them by the time anyone reads this.

Write only what cannot be measured:

- **Approach.** The shape of the solution and why this shape rather than an obvious alternative.
- **Trade-offs.** What you chose against, and what it would cost to choose differently.
- **Risk.** Where you think this is most likely to be wrong, or hardest to change later.
- **Deliberate omissions.** What the spec allows that you did not do, and why.

If you found the specification ambiguous or underdetermined, say exactly where. That is the
most valuable thing this file can contain: it routes back to the task author instead of
becoming a defect argued about later.
