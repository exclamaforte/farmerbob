# Capability probe

Small task. It exists to verify this agent can do real multi-turn work in this repo: read a
file, understand what is there, modify it, run the tests, and fix what breaks.

## What to do

1. Read `crates/farmerbob-core/src/ids.rs`. The id types are generated by a `define_id!`
   macro — note how that works before editing.
2. Give every id type a method `pub fn short(&self) -> String`, returning the first 8
   characters of the id's hyphenated UUID string. It must never panic, including if the
   string is somehow shorter than 8 characters.
3. Add unit tests in the same file covering: `short()` returns 8 characters for a fresh id,
   and two different ids produce different `short()` values.
4. Run `cargo test -p farmerbob-core` and make sure the whole crate still passes.

## Rules

- Touch no file other than `crates/farmerbob-core/src/ids.rs`.
- No `unwrap()`, `expect()` or `panic!` on any reachable path outside `#[cfg(test)]`.
- Do not add dependencies. Do not change any existing public signature.

When done, say in one line what you added.
